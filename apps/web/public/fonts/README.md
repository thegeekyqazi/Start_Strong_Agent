# Locally served Red Hat fonts

Unmodified Google Fonts binaries for the exact Red Hat Display600, Mono400/500 and
Text400/500/600 faces selected by UI-001. Source URLs and SHA-256 values are recorded in
sources.json; each family's copyright/SIL Open Font License is included beside the fonts.
These files are served with the app so the existing no-external-request browser contract
works while retaining Sawaab's selected typography. No font service is contacted at runtime.

Upstream sources: https://github.com/google/fonts/tree/main/ofl/redhatdisplay,
https://github.com/google/fonts/tree/main/ofl/redhatmono,
https://github.com/google/fonts/tree/main/ofl/redhattext.

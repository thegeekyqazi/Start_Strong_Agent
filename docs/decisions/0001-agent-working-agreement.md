## Accepted user decisions

The project owner initializes the repository and project setup. Per-feature development specs will be supplied one at a time after selecting a lane. Agents work on developer/task branches and integrate through PRs, with detailed commits/PRs citing the engineering document. Agents identify meaningful departures and explain why; routine implementation decisions may use developer discretion.

Initial-bootstrap assignments to other lanes in engineering section 20 are superseded for that initial setup. Subsequent feature/data/migration responsibilities still apply unless a task spec or the owner changes them. AGENTS.md records this distinction without silently changing the engineering baseline.

## Proposed operational defaults

The task-branch naming, small PRs, role-based handoffs, exact-ref communication, cross-review and compatibility practices in this kit implement those decisions. They are adjustable team defaults, not additional previously approved product requirements. GitHub server rules must be configured by the owner; a documentation rule alone cannot enforce them.

No feature lane has been selected for the project owner, no feature development spec has been generated, and no source repository has been created or modified by this kit.
